Correlation-NN segmentation results

Source: · methods · repository files

What this experiment asks: each image becomes a spin Hamiltonian (Ising or XXZ), and we measure the spin–spin correlation matrix C of its thermal (Gibbs) state. Can a trained neural network read C and recover the object mask better than the paper's simple seed-sign rule (Algorithm 1)?

Data: 100 Weizmann single-object images, shrunk to 16×16 grayscale, scored against human masks. Each method is trained and evaluated with 5-fold cross-validation, so every image is scored exactly once by a model that never saw it.

All 100 images were used in earlier project development, so this is internal validation, not a fresh external test. Better learned decoding is not evidence of a quantum advantage.

    Glossary

    Ising model
    Spins interact only through their Z components. Its Gibbs state is a classical probability distribution, so it can be simulated classically.
    XXZ model
    Adds XX and YY "exchange" terms of strength g, which don't commute with ZZ. This is the genuinely quantum version.
    Coupling Δ
    Edge strength between neighbouring pixels, Δ = arctan[α(τ − d)], where d is their intensity difference. Similar pixels get Δ > 0 and prefer aligned spins.
    Gibbs state
    The thermal state exp(−bH)/Z. Larger b means colder and more ordered.
    Correlation matrix C
    C[i,j] = ⟨ZiZj⟩ for every pixel pair, estimated from 8,192 Z-basis snapshots per image. Positive means the two pixels tend to agree. C = 4Γ in the paper's notation.
    Seed
    A pixel whose label is known in advance. Here it's an interior foreground pixel taken from the human mask. Seeds label the readout; they don't pin spins.
    Algorithm 1 (sign rule)
    The paper's rule: a pixel is foreground if its correlation with the foreground seed is positive.
    Neural decoder
    A small CNN or graph network that takes the whole C matrix plus pixel coordinates and outputs a mask. It never sees image intensities.
    Cross-validation
    5 outer folds of 64 training, 16 validation and 20 test images. Settings are tuned on validation images, then each test image is scored once.
